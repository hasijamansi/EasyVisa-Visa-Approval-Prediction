# EasyVisa-Visa-Approval-Prediction
Machine Learning project for predicting visa approval outcomes using classification models.
## Objective
Predict visa approval outcomes using machine learning techniques.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Model Building
5. Model Evaluation

## Key Insights
- Identified important factors affecting visa approval.
- Built classification models for prediction.
- Generated business recommendations based on model results.
